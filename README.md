# QWTA

QWTA uses continuous-time quantum walks to propagate traffic signals over a graph of sensors. The models forecast traffic speed on METR-LA from irregularly sampled histories.

[中文运行说明](README_zh.md)

## Directory structure

```text
QWTA/
├── config.json          # Model, data and training settings
├── requirements.txt     # Python dependencies
├── main.py              # Training entry point
├── train.py             # Training, validation and checkpoint selection
├── test.py              # Evaluate a saved checkpoint
├── dataset/             # METR-LA loading and chronological splits
│   ├── data/            # Local METR-LA files
│   ├── dataset_build.py
│   ├── dataset_split.py
│   └── dataset_test.py
├── model/               # QWTA variants and classical baselines
├── utils/               # Configuration and checkpoint utilities
└── runs/                # Checkpoints and metrics generated by training
```

## Setup

Use Python 3.10 and run the commands below from the repository root.

```powershell
python -m pip install -r requirements.txt
```

Place `adj_mat.npy` and `node_values.npy` in `data/`. When `data/` is absent, the loader looks in `dataset/data/`. Use `--data-dir` to point to another local copy.

## Train and evaluate

Run a CPU smoke test with one epoch and one batch of two windows from each split.

```powershell
python -B main.py --smoke --model QWTA_GR --output-dir runs/smoke
```

The run saves `best.pth`, `last.pth`, `config.json`, and `result.json` in a new directory under `runs/smoke/QWTA_GR/`. It reloads the checkpoint with the lowest validation MSE and reports test MSE and MAE. The following PowerShell commands evaluate the checkpoint independently.

```powershell
$run = Get-ChildItem -LiteralPath .\runs\smoke\QWTA_GR -Directory |
    Sort-Object LastWriteTime -Descending | Select-Object -First 1
python -B test.py --checkpoint (Join-Path $run.FullName 'best.pth')
```

Choose a Table I model with `--model`. The accepted values are `QWTA_base`, `QWTA_GR`, `GAT`, `GCN`, `Transformer`, and `GIN`. `QWTA_AD` is an alias for `QWTA_GR` in historical configurations.

For a full training run, omit `--smoke`. The default [configuration](config.json) uses MASK3, retaining 9 of 12 historical observations, with a chronological 70/20/10 train, validation, and test split. Pass `--config` to use a different training schedule, mask, or seed. QWTA-GR requires at least two retained observations. The `checkpoint_path` setting loads model weights and starts a new optimizer.
